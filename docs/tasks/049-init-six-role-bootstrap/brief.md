## Constraints

### Non-negotiable constraints

- Every `init/` prompt keeps its existing shape: a `>` context header naming
  what was already generated, a "what this document is" section, guidance on
  how to conduct the interview, an "após gerar" section, and an explicit next
  step. Do not restructure the format.
- Prose stays pt-BR (R9, human-edited interface). Any block the new project's
  agent consumes as canonical output is English — same split the existing
  prompts already follow.
- No prompt exceeds ~200 lines, matching the current range (124–191).
- The two new prompts are numbered `08` and `09`, continuing the sequence.
- No new runtime dependency (R2). Nothing in this task touches a manifest.

### Conventions

- R9 language split; R10 / G-R3 Conventional Commits; G-R2 branch naming.
- Commit verbs come from the allowlist SSOT in
  `.claude/skills/pre-commit-self-audit/SKILL.md`.

### Architectural decisions already made (do not revisit)

- **D1 — Scope is all three layers.** Update the seven existing prompts, add
  a machinery prompt, and add a `PROCESS_MAP` generator. A scope that stops
  before the machinery leaves the new project non-functional; one that stops
  before `PROCESS_MAP` reintroduces the exact gap Saci just closed.
- **D2 — The machinery is copied and adapted, not generated by interview.**
  Regenerating `closer.md` by interview would discard N1–N3, which cost a
  full calibration pass in task 047. The prompt therefore instructs copying
  the contracts and walking an explicit adaptation checklist.
- **D3 — Teach six roles, prescribe a minimum subset.** The generated
  `AGENT_PLAYBOOK` explains all six roles and why each exists, then prescribes
  starting with Mentor + Orchestrator + executor and names the growth
  triggers: planner when delegation becomes repetitive, brief-validator when
  briefs drift mechanically, closer when the diff has architecture to violate.
  Saci reached six roles across 48 tasks; imposing the endpoint on an empty
  project is the premature abstraction `CLAUDE.md` A3 forbids.
- **D4 — One machinery prompt, not two.** Agents and skills install together
  in `08`, because the adaptation checklist spans both and splitting it
  invites installing half.
- **D5 — `PROCESS_MAP` is generated last.** It maps what exists; generating it
  before the machinery would document an absent surface.
- **D6 — `harness/README.md` records the copy-and-adapt exception.** That
  file's closing principle section holds that living documents beat static
  templates, and that each canonical artifact is produced by interview rather
  than copied from a template. D2 is a real exception to that principle for
  the machinery layer, and it is recorded rather than left as a silent
  contradiction.
